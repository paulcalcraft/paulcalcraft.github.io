Neural net objective: Take 3 input values (integer tokens 0-4) and output the average value of the tokens.

Weights and embedding points are interactive. Drag them around to see how it affects the loss. Scroll down ⬇️ for details

Loss: N/A 
const vocabSize = 5;
const embedDim = 2;
const seqLength = 3;
const batchSize = 32;

model = tf.sequential();
model.add(tf.layers.embedding({inputDim: vocabSize, outputDim: embedDim, inputLength: seqLength}));
model.add(tf.layers.flatten());
model.add(tf.layers.dense({units: 1}));

model.compile({
  optimizer: tf.train.adam(0.01),
  loss: 'meanSquaredError',
});

// Generate fixed dataset
X = tf.randomUniform([batchSize, seqLength], 0, vocabSize, 'int32');
Y = X.sum(1).div((vocabSize-1) * seqLength).expandDims(1); // Normalize sum to [0, 1] and add a dimension

Explanation

Neural net objective: Take 3 input values (integer tokens 0-4) and output the average value of the tokens.

Model: A two dimensional embedding is learned for each of the 5 tokens. A single dense layer of 6 weights is learned to transform the 3 concatenated/flattened embeddings into the target output (the average of the 3 inputs).

Example 1: (0,1,2) ➔ 1

Example 2: (4,3,2) ➔ 3

Exa... you know what averages are.

Questions

  1. How does the model solve this? Retry the training a few times to see if it always arrives at the same solution.
  2. What's the easiest way to solve it with the fewest number of non-zero weights?
  3. Can you define the rules or equations that define the sets of weights that correctly compute the average?

You can:

  • Start, pause, and resume training
  • Drag embedding points and density weights in the graphs to change them
  • Freeze either the embeddings or the dense layer, or both, to see how it affects training
